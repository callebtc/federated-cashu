# federations: setting
what is a federation? instead of one mint you have multiple federation members.

improves: security assumptions, if the system is byzantine-fault tolerant it survives as long as the majority remains honest.

what does federation mean? not only cryptography: threshold signatures, multisig, etc yes. but also advancement of state: state observations and rules for state transitions must be enforced in consensus: consensus rules.
